## How I built this
I wanted a portfolio that felt modern, fast, and completely customized. 
* **Tech Stack:** I built this using pure **HTML**, **Tailwind CSS** (for that clean, dark-themed glassmorphism design), and **Vanilla JavaScript** for smooth scrolling animations.
* **Features:** It includes a hero intro, my technical skills, a detailed timeline of my experience, my featured MERN stack projects, and my certifications (Cisco, Hackathons, etc.).

## Want to run it locally?
Since it's built with static files, running it yourself is super easy:
1. Clone this repository to your computer.
2. Just double-click the `index.html` file to open it in your browser (or use VS Code Live Server if you want to play with the code).
