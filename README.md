## 🌟 Portfolio Highlights
This repository holds the source code for my portfolio website. I designed it from scratch to be dark-themed, incredibly fast, and visually striking using **Glassmorphism**.

✨ **Key Features:**
- **Hero Section:** A clean, modern, and welcoming introduction.
- **Experience Timeline:** Showcasing my professional roles.
- **Project Showcase:** Highlighting my full-stack work (Course Selling App, Zomato Data Analysis, etc.).
- **Certifications Grid:** Sleek, clickable cards that link directly to my verified credentials (Cisco, Hackathons, and MLSA).

---

## 🚀 Run It Locally
Since the portfolio is completely static, it requires absolutely zero setup!
```bash
# 1. Clone the repository
git clone https://github.com/aribanaz11/ariba-naz-portfolio.git

# 2. Open the folder
cd ariba-naz-portfolio

# 3. Just double-click index.html to open it in your browser!
```
